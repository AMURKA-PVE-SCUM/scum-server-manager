## 🚀 Быстрый старт и установка

### 1. Скачать менеджер
Скачайте последний готовый установщик из раздела **[Releases](https://github.com/AMURKA-PVE-SCUM/scum-server-manager/releases/latest)**:
* `SCUM.Server.Manager.Setup.X.X.X.exe`
* Запустите установку и откройте приложение.

### 2. Серверный RCON мод (обязательно для расширенных функций)
Для полноценной работы RCON, досье игроков, чат-команд, аирдропов и карты транспорта требуется серверный мод **SCUM-RCON**:

* **Репозиторий:** [github.com/AMURKA-PVE-SCUM/scum-rcon](https://github.com/AMURKA-PVE-SCUM/scum-rcon)
* **Архив для загрузки:** [SCUM-RCON-Win64.zip](https://github.com/AMURKA-PVE-SCUM/scum-rcon/releases)

**Установка мода:**
1. Распакуйте содержимое `SCUM-RCON-Win64.zip` в каталог сервера:
   ```text
   <Папка_Сервера>\SCUM\Binaries\Win64\
   ```
2. Откройте `ue4ss\Mods\scum_rcon\config.ini` и задайте надёжный пароль:
   ```ini
   [rcon]
   bind_address = 0.0.0.0
   port         = 28015
   password     = ВашПароль
   ```
3. Запустите сервер `SCUMServer.exe`.
4. В менеджере укажите host (`localhost`), порт `28015` и ваш пароль RCON.

Подробная инструкция доступна в [RCON_SETUP.md](RCON_SETUP.md).

## 🌟 Возможности

### 🖥️ Управление сервером
- Запуск / остановка / перезапуск сервера
- Мониторинг в реальном времени: RAM, аптайм, FPS, количество игроков
- Авто-старт при запуске приложения, авто-перезапуск при краше (с защитой от циклических рестартов)
- Параметры запуска: порт, QueryPort, MaxPlayers, -NoBattlEye, -fileopenlog
- Скрытие консоли сервера после запуска

### 📦 SteamCMD
- Автоматическая установка SteamCMD в один клик
- Проверка обновлений сервера (сравнение Build ID через api.steamcmd.net)
- Обновление сервера с прогресс-баром в реальном времени (3 попытки, авто-восстановление)
- Блокировка авто-обновления SteamCMD
- Ручная переустановка сервера

### 📡 RCON (Source RCON протокол)
- Подключение / отключение, авто-переподключение при обрыве
- Отправка любых RCON команд через веб-панель или десктопный интерфейс
- Логирование всех команд в `logs/rcon_commands.log`

### 🌐 Веб-панель (HTTP, порт 8080)
Полноценный веб-интерфейс с авторизацией по Bearer-токену:

#### Дашборд
- Статус сервера, онлайн, аптайм, RAM, RCON
- Live-консоль (SSE), вывод лога сервера в реальном времени
- **Версия приложения** + проверка обновлений (автообновление через GitHub Releases)

#### Интерактивная Карта
- 3 варианта карты: цветная, серая, оранжевая (4096x4096)
- **Игроки**: позиции в реальном времени (через `ListPlayers`)
- **Флаги территорий**: базы игроков из `SCUM.db`
- **Транспорт**: весь транспорт на карте с владельцами
- **Секторная сетка**: D4–Z0 как в игре, сектора 5×5
- Контекстное меню ПКМ: телепорт по координатам, копирование координат

#### Управление игроками
- Онлайн-список с автообновлением (5 сек)
- Карточки игроков: атрибуты, навыки, инвентарь, баланс, золото, Fame
- **Действия**: GodMode, Immortality, NamePlates, Kill, Silence, Knockout, Kick, Ban
- **Выдача**: предметы (с автокомплитом), транспорт, деньги, золото, Fame
- **Навыки**: установка всех 22 навыков на макс одной кнопкой
- **Атрибуты**: сила, ловкость, выносливость, интеллект (1–10)
- **Сообщения**: Announce (глобал), Notify (Info/Warning/Error/Success), Chat (в раздельный канал)
- **Телепорт**: по координатам, в сохранённые локации, к игроку
- **Сброс карго**: авто-определение координат игрока через `ListPlayers`

#### Игровой Чат
- SSE-трансляция игрового чата в реальном времени
- Фильтры по каналам (Global, Admin, Local)
- Отправка сообщений от имени бота с выбором любого ника отправителя
- Поддержка русского языка (UTF-16LE с авто-выравниванием)

#### Игровые модули
- **Наборы (Packs)**: стартовый и ежедневный наборы с кулдаунами, VIP-бонусы
- **VIP**: добавление игроков со сроком действия, бонусы к наборам
- **Телепорты**: точки с названием, координатами и ценой
- **SaveHome**: сохранение позиции, телепорт домой
- **Аирдроп**: ручной и авто-дроп (`SpawnInventoryFullOf`), система калибровки высоты (125 точек), авто-дроп по таймеру и мин. игрокам
- **Рейтинг**: учёт времени онлайн, денег, золота, Fame, таблица лидеров, чёрный список, `!рейтинг` в чате
- **Награды**: почасовые (за час онлайн) и топ-игроков (за период с множителем)

#### WARGM — магазин + автовыдача
Полная интеграция с [WARGM.RU](https://wargm.ru):
- **Карточки товаров** — привязка `offer_id` к правилам выдачи
- **Типы выдачи**: предметы, транспорт, навыки (все/один), атрибуты, деньги, золото, **слава (Fame)**, карго-дроп, VIP
- Автоматическая выдача по команде игрока `!wargm` / `!варгм`
- Защита от дубликатов (operation_claim + SQLite база wargm_deliveries)
- Rate-limit, экспорт/импорт карточек в JSON, дебаг-режим
- Логирование API-запросов и выдач

### 🗄️ База данных SCUM.db (чтение + запись)
- Игроки: профили, кошелёк (деньги + золото), Fame, флаги
- Навыки: все 22 навыка с уровнем и опытом
- Атрибуты: сила, телосложение, ловкость, интеллект, вес, рост, возраст
- Инвентарь: рекурсивное дерево предметов, быстрые слоты
- Отряды: список, участники, ранги, счёт
- Транспорт: все ТС, состояние и владельцы
- Флаги территорий с координатами
- Банк-аккаунты с балансами

### 💬 Чат-команды (внутриигровые)

| Команда | Алиасы | Описание |
|---------|--------|----------|
| `!help` | `!помощь`, `!commands` | Список команд |
| `!balance` | `!баланс` | Баланс (деньги + золото) |
| `!location` | `!локация`, `!координаты` | Координаты игрока |
| `!online` | `!онлайн` | Список игроков онлайн |
| `!startpack` | `!стартпак` | Стартовый набор (с кулдауном) |
| `!dailypack` | `!дейлипак` | Ежедневный набор (24h кулдаун) |
| `!wargm` | `!варгм` | Проверка/получение покупок из WARGM |
| `!teleport` | `!телепорт` | Список доступных телепортов |
| `!vip` | `!вип` | Статус VIP + оставшиеся дни |
| `!nameplates` | `!ники` | Включить никнеймы над головами |
| `!savedom` | `!сохранитьдом` | Сохранить позицию как дом |
| `!home` | `!дом` | Телепорт домой |
| `!homes` | `!дома` | Список домов |
| `!рейтинг` | `!rating` | Статистика игрока и топ |

### 🔌 Публичный API (для сайтов и ботов)

Публичный API позволяет внешним сайтам и ботам получать данные сервера **без авторизации** (онлайн, статус, рейтинг) напрямую из кэша:

| Endpoint | Описание |
|----------|----------|
| `GET /api/health` | Пинг: `{ ok: true, version }` |
| `GET /api/public/status` | `{ serverName, online, maxPlayers, running, uptime, fps, memoryMB, currentTime, lastUpdated }` |
| `GET /api/public/players` | Список онлайн игроков с временем сессии, балансами и очками |
| `GET /api/public/leaderboard` | Таблица лидеров топ-20 |
| `GET /api/public/config` | Конфигурация публичного API |
| `GET /api/docs` | Встроенная интерактивная HTML-документация с примерами |
