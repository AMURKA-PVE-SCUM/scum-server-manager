# SCUM Server Manager — Android (Flutter)

Нативное Android-приложение с собственным мобильным UI, подключающееся к
веб-панели **SCUM Server Manager** через её HTTP API (`http://<host>:<port>/api/...`).

## Возможности
- Статус сервера (запущен/ост`, игроки, аптайм, RAM, CPU, FPS), Старт/Стоп/Рестарт
- Онлайн-игроки с деталями, кик/бан
- Чат в реальном времени (SSE)
- RCON-консоль (SSE + отправка команд)
- Паки (выдача, состав), предметы с иконками, телепорты
- VIP, SaveHome, Авто-сообщения, Награды, Рейтинг, SCUMDB (сквады/транспорт/флаги)
- Аирдроп, Boss-бот, обновление сервера

## Настройка доступа
1. В веб-панели менеджера включите webPanel и укажите порт (по умолчанию 8080).
   Сервер слушает `0.0.0.0` — доступен из сети.
2. Для доступа из интернета пробросьте порт на роутере или используйте туннель.
3. В приложении укажите адрес `http://<IP_или_домен>:<порт>`, логин и пароль панели.

## Сборка
Установите Flutter SDK, затем:
```
cd android_app
flutter pub get
flutter build apk --release
```
APK появится в `build/app/outputs/flutter-apk/app-release.apk`.

## Заметки
- Токен сохраняется в `SharedPreferences`.
- SSE-потоки (чат/консоль) используют токен в query-параметре `?token=`.
- Для macOS/internet-подключения сервер использует HTTP без TLS — используйте
  HTTPS-обратку (например, Caddy/nginx) при публичном доступе.
